## Skriptin tarkoitus

Tarkoituksena on tehdä komentorivillä toimiva skripti,
joka automatisoi tietokoneen ylläpitoon liittyviä tehtäviä.

Skriptillä on tarkoitus automatisoida esimerkiksi:

- tietokoneen perustietojen tarkistus
- levytilan tarkistus
- Windows-palveluiden tarkistus
- raportin tekeminen
